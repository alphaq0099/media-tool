# Support

Check the [user guide](docs/user-guide.md) and **Tools → Dependencies** first.

For a problem report, include the application version, operating system, chosen
tool/task, expected result and what happened. Reproduce with a small disposable
input where possible.

Select the job in **Queue → History**, then use **Tools → Export support report**.
This file contains technical versions, selected safe settings and outcomes. It
does not include input/output filenames, paths, passwords, metadata, custom titles,
timestamps or free-form error messages. Describe the error separately after
removing private information.

**Save report** is the full diagnostic job record. It can include local paths,
filenames and metadata; do not assume it is suitable for public sharing.

Use [GitHub Issues](https://github.com/alphaq0099/media-tool/issues) for reproducible, non-sensitive bugs. For a
security problem, follow [the security policy](SECURITY.md).
