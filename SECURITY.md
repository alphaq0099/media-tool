# Security reports

Version 1.0.x is the initial supported application series. Keep separately
installed media/OCR/Office tools updated through their providers.

Do not post passwords, private documents, full job reports or exploitable
security details in a public issue. If the repository provides **Security →
Report a vulnerability**, use GitHub's private vulnerability reporting. The
repository owner must enable that feature before accepting private reports.

When private reporting is unavailable, open a public issue requesting a private
contact channel without disclosing the vulnerability details. A response-time
guarantee has not been established.

Repository: https://github.com/alphaq0099/media-tool
